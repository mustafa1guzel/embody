# Research provenance, reproducibility and reports

`EMBODY_RESEARCH_MANIFEST_V1` stores exact typed project/campaign configuration,
source-bound descriptor metadata, SI parameter domains and explicit cases,
criteria, strategies/seeds, context identities and locally rechecked evidence
references/result/trajectory/model hashes. It contains no trajectory duplicates,
credentials, host paths, certificates or executable payload.

Import validates exact schema/version/hash/registered contracts, bounds, batch
identities, references and total size. Unknown fields, code/path/URL content,
unsupported model/controller and altered descriptor contracts reject. Source-stale
context needs explicit archival acknowledgement. Imported projects receive a new
independent identity; review/transfer/completion authority is reset. Saved evidence
must verify through the existing local reader. Unavailable external claims remain
unverified; imports never dispatch provider/native calls or apply geometry.

Manifest comparison ignores title coincidence and compares actual campaign
configuration, descriptor/settings/source and evidence values. Differences list
field paths; identical configuration is not fresh physical reproduction. An
explicit reproduction proposal copies only supported numerical values, preserves
source drift and needs new review plus existing native confirmation.

## Evidence graph

Version1bounded graph:512nodes/1024edges, stable IDs, duplicate/dangling reference
rejection and deterministic sorted serialization. Types: question, hypothesis,
campaign, proposal, prediction, model, controller, execution, verified case,
finding and report. Relationships include investigates, uses_model/controller,
references, derived_from and included_in. Derivation edges form a DAG; unrelated
reference cycles are not prohibited. Findings derive only from verified cases,
not predictions. Accessible filtered dependency lists show exact references.
Evidence is reverified on view/report, not trusted from a stored badge.

## Deterministic report

Preview/export `EMBODY_RESEARCH_REPORT_V1` as Markdown or JSON with title, question,
hypotheses, methodology, analytical predictions, verified measurements, boundary
status, sensitivity, eligible comparisons, findings, limitations, reproducibility
and future work. Select a campaign and hypotheses; deterministic discussion is
optional. Text is escaped and displayed as text, never unsafe HTML.

An empty/unmeasured project produces RESEARCH_PROPOSAL_ANALYTICAL_STUDY, not an
empirical success. Saved measurements are SAVED_EVIDENCE_RESEARCH_ANALYSIS. Unique
case counts are deduplicated, error states never become physical failures, and
external reference cases never become executions of a proposal. Changed evidence
withholds dependent numerical findings. All factual numeric claims trace to
verified case/metric and summary/result/trajectory digests. Hypotheses and future
recommendations are not measurements. Report generation makes no automatic AI call.

The original v0.4 native source identity is historical after API route changes;
new verification must create new evidence. The original v0.6 preview performed
read-back only. Subsequently, separately
approved current-source v0.6.2 native runs produced four cases/eight rollouts/4,800
steps and one measured refinement. [Two public exports](../examples/adaptive-rail-study/README.md)
retain their separate original capture/source identities and unchanged case bytes.
No import or documentation update renews their consumed authority. Any further
native point or live AI integration requires separate exact approval.


Research-only manifest and batch identities use tagged semantic JSON values:
finite numbers map to IEEE754 double hex, signed zero is normalized; booleans,
strings, arrays and objects retain distinct tags. Thus browser4.0→4 and exponent
spelling changes preserve identity without accepting true as1. All bounded integer
fields are below2^53. Existing native/evidence/source digests are unchanged.
A browser-numeric round-trip is tested independently; import still resets review.
