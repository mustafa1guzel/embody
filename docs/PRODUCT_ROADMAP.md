# Product roadmap

## v0.7 — current rail workflow foundation

Home and actual named numerical projects; shared Design/Program/Simulate/Debug/
Verify context; genuine saved 3D/measurement playback; deterministic physical
issues; review-only improvements/preparation; existing specialized tools retained.
General mechanical and rail project models remain separate. This is a working
bounded foundation, not the completion of every all-model Product Alpha objective.

## v0.8 — Robotics Developer Toolkit

- Introduce an explicitly versioned common engineering project descriptor without
  silently migrating applied heads or attaching unrelated passing evidence.
- Review additional real model/import contracts: supported URDF/MJCF structure,
  assets, joints, limits and bounded native admission. Parsing is not execution.
- Add genuinely supported controller configuration/development and source-aware
  revision comparisons; no arbitrary execution or controller installation bypass.
- Add physical test scenarios and reusable regression suites with exact contexts,
  measurements and fresh finite execution approval for any new model/controller.
- Improve rail-plan editing/rename/export/recovery and preserve independent
  mechanical/circuit workflows until explicit validated integration exists.

## v0.9 — Intelligent Engineering

Separately authorized, budgeted model interpretation → typed proposal → strict
validation → human review → finite approved execution → verified evidence →
interpretation. Extend the existing orchestrator/provider accounting; do not
pretend deterministic explanations are live model reasoning.

## v1.0 — coherent installable bounded product

Reproducible supported local setup, clear model/controller capability contracts,
recoverable project state, usable physical debugging and tested integrations.
Document platform, proxy, security and authorization limits rather than claiming
unrestricted robotics or real-world safety.

No outreach, recruitment, payment, fundraising, marketing analytics, cloud team
service or external launch is included in the current engineering milestone.
