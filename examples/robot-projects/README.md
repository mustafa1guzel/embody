# Numeric robot project starters

[Rail](rail.json) and [rover/ramp](rover.json) are explicit developer-authored
EMBODY_ROBOT_PROJECT_V1 configurations, not measured evidence, AI output or applied
assemblies. Import through Home → Import robot project. Export/re-import preserves
the declaration and creates a distinct numeric project; no saved result, native
consent, source file, personal path, certificate or execution authority is included.
Rover native verification is pending separate exact approval. See the
[toolkit guide](../../docs/MULTI_MODEL_TOOLKIT.md).
